# 主流平台支持边界

本服务仅处理用户有权保存的公开、无 DRM、无需登录的内容；不接收用户 Cookie，也不求解验证码、WAF 或平台反爬参数。

- 抖音：优先展开 `v.douyin.com` 短链，再尝试公开元数据接口；公开接口未返回媒体流时，降级为 `yt-dlp`。公开接口成功时，直链和服务端下载都会复用已解析的公开 MP4 源。若平台要求会话或反爬验证，将返回明确的不可解析提示。
- 小红书：展开 `xhslink.com` 短链并保留作品页的 `xsec_token`，交由内置 `yt-dlp` 的 XiaoHongShu 提取器解析。平台未返回公开视频流时，将返回明确提示。
- YouTube：使用 `yt-dlp-ejs` 官方组件与 Node.js 24 处理公开播放器 JavaScript 挑战。若 YouTube 仍要求“确认非机器人”，服务不会尝试规避该验证，而是返回明确提示。

YouTube 等平台通常提供音视频分离的自适应流。此类格式不会再向浏览器重定向视频轨而导致无声：API 自动将其创建为服务端任务，由 `yt-dlp` 和 `ffmpeg` 合并成 MP4 后再交付。
