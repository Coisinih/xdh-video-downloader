# VidNest 需求分析

## 用户与目标
面向希望将有权保存的公开视频下载到本地的桌面和移动浏览器用户。首版价值是快速解析、选择格式并可靠交付文件。

## MVP 范围
- 单个 HTTP/HTTPS 公开视频链接解析；展示标题、封面、时长、格式与估算大小。
- 服务端下载后提供 2 小时临时链接，或以短期令牌进行极速直连/安全代理。
- 无数据库、无账号、无支付、无持久历史。

## 合规边界
仅处理公开、无 DRM、无需 Cookie 的内容。拒绝私密、付费、DRM 或需要登录授权的内容。用户应确认自己拥有保存内容的权限并遵守来源平台规则与当地法律。

## 后续方向
会员可增加配额、历史与批量任务；AI 可增加转录、摘要和字幕翻译。这些能力均不属于当前 API 契约。
